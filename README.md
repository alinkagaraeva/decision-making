## Домашнее задание 1. Находится в папке hw_1.

Работа с pandas, визуализация данных и распределение студентов по курсам.

Описание и решение находятся в [hw_1/homework_practice_01.ipynb](hw_1/homework_practice_01.ipynb).

В папке hw_1 также находятся:
- исходные данные end_seminar.xlsx;
- эталон проверки task_2_check.csv;

Для запуска нужны python, pandas, numpy, matplotlib, seaborn,
openpyxl и ipykernel. Ячейки следует выполнять последовательно,
используя папку hw_1 как рабочую директорию.
